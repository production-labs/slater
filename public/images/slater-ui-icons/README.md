# Slater UI icon set

Clean vector reconstructions based on the supplied Slater UI mockup. These are newly drawn icons, not pixel traces.

## Specifications

- 24 × 24 viewBox
- 1.6 px rounded strokes
- `currentColor` for easy recoloring
- No embedded fonts, bitmaps, masks, or external dependencies
- Editable SVG paths and basic shapes

The requested `edit-pencil.svg` is included as an extension matching the same visual language.
